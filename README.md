# C Student Grades

A console-based student grade management system developed in C
to practice structures, arrays and modular programming.

## Features

- Register students and their grades
- Calculate the average grade
- Find the student with the highest grade
- Display all registered students
- Organize the application using separate functions

## Concepts

- `struct`
- `typedef`
- Arrays of structures
- Functions
- Function parameters
- Return values
- String manipulation
- Iteration
- Conditional statements

## Technologies

- C
- GCC

Academic project developed as part of my Computer Engineering
